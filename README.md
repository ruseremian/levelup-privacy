# Borna privacy policy

The public privacy policy of the Borna game (formerly LevelUp), in English, Russian and French:
https://ruseremian.github.io/levelup-privacy/

`index.html` is generated from the app's own strings (`privacy.*` in
`app/src/core/i18n/{en,ru,fr}.json` of the LevelUp repository), so the page
and the Settings screen always show the same text. Change the policy there
first, then regenerate this page with `node scripts/privacy-page.mjs > index.html`
in the LevelUp repository and commit the result here.
